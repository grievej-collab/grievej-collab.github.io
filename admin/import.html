Course Importer Canvas .imscc → course site project

Ready Back to Admin

This converts a Canvas course export (.imscc) into a new project folder that the admin tool can manage: modules and items in data/structure.json, all media in media/. Everything runs locally in your browser (Chrome or Edge) — nothing is uploaded anywhere. Before you start, create a new empty folder for the course and copy the admin folder into it from an existing course project (or use step 3 below to do the copy for you).
