This tool runs entirely in your browser -- nothing is uploaded anywhere. Click Open Project Folder and select the course project folder (the one containing data, media, admin, and publish). Requires Chrome or Edge (Firefox and Safari don't support the local file access this tool needs). Drag to rearrange; click the ✎ on an item to edit its content; hover a row for duplicate / delete buttons. Have another course as a Canvas export? Use the Course Importer to turn a .imscc into a new project folder.
